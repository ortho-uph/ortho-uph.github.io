# ระบบยาค้างจ่าย

ระบบติดตามยาที่จ่ายไม่ครบตามแพทย์สั่ง แยกจากระบบยารีฟิวเดิม (`refill-medication/`) และใช้ฐานข้อมูลของตัวเอง

- `index.html` คือหน้าเจ้าหน้าที่ ต้องเข้าสู่ระบบด้วย PIN
- `status.html` คือหน้าที่ผู้ป่วยเปิดจาก QR บนใบแจ้ง ไม่ต้องเข้าสู่ระบบ
- `core.js` คือกฎของระบบที่ใช้ร่วมกันทั้งสองหน้า เช่น สถานะ การแบ่งนัด วันหยุด ข้อความถึงผู้ป่วย และรหัสไปรษณีย์
- `config.js` เก็บ Web App URL ของฐานข้อมูล
- `apps-script/Code.gs` คือ backend บน Google Apps Script

## ติดตั้งฐานข้อมูลใหม่

1. สร้าง Google Sheet ใหม่ ตั้งชื่อตามสะดวก เช่น "ระบบยาค้างจ่าย"
2. ในชีตนั้นเปิดเมนู **Extensions → Apps Script** ลบโค้ดตัวอย่าง แล้ววางเนื้อหาทั้งหมดของ `apps-script/Code.gs`
3. เปิด **Project Settings → Script Properties** เพิ่ม Property ชื่อ `API_KEY` ค่าเป็นข้อความสุ่มยาวอย่างน้อย 16 ตัวอักษร เก็บค่านี้ไว้ ใช้ตอนตั้ง PIN ครั้งแรก
4. กด **Deploy → New deployment** เลือกชนิด **Web app** ตั้ง *Execute as* เป็น **Me** และ *Who has access* เป็น **Anyone** แล้วกด Deploy และอนุญาตสิทธิ์
5. คัดลอก Web app URL ที่ลงท้ายด้วย `/exec` มาใส่ใน `config.js` ที่ `endpoint: '…'` แล้ว push ขึ้น GitHub Pages
6. เปิดหน้าเจ้าหน้าที่ กด **ตั้งหรือเปลี่ยน PIN** ใส่ API key จากข้อ 3 และ PIN ใหม่ 4–8 หลัก

ระบบจะสร้างแท็บ `Slips` (ใบแจ้ง) `Holidays` (วันหยุดราชการ) และ `DrugNames` (รายชื่อยา) ให้เองเมื่อใช้งานครั้งแรก

ถ้าแก้ `Code.gs` ภายหลัง ต้องกด **Deploy → Manage deployments → Edit → Version: New version** ทุกครั้ง URL จะยังเป็นค่าเดิม

## ความปลอดภัย

- ไม่มี PIN ตั้งต้น ต้องตั้งด้วย API key ก่อนใช้งาน และระบบเก็บ PIN แบบ hash
- กรอก PIN ผิดติดกัน 10 ครั้ง ระบบจะล็อกการเข้าสู่ระบบทั้งระบบ 15 นาที
- หน้าผู้ป่วยได้รับเฉพาะชื่อที่ปิดนามสกุลแล้ว รายการยา และวันนัด ไม่ได้รับ HN เบอร์โทร หรือที่อยู่
- ข้อความที่ผู้ป่วยเห็นใช้คำว่า "ยาส่วนที่เหลือ" ไม่บอกว่ายาหมดหรือไม่พอ

## วันหยุดราชการ

ข้อมูลตั้งต้นมีเฉพาะวันหยุดที่วันที่ตายตัว วันหยุดตามจันทรคติ (มาฆบูชา วิสาขบูชา อาสาฬหบูชา เข้าพรรษา) และวันหยุดพิเศษตามมติ ครม. ต้องเพิ่มเองทุกปี จากปุ่ม **📅 วันหยุด** หรือแก้ในแท็บ `Holidays`
