# pharma-roster

ไฟล์ใน repository นี้มีเฉพาะหน้าเว็บ ไม่มีข้อมูลเวร รายชื่อ หรือรหัสส่วนตัว ข้อมูลเก็บใน API ส่วนกลางที่ตรวจรหัสแยกรายคน ระบบผู้จัดตารางและซอร์สเต็มเก็บแยกไว้ใน repository private
